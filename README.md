## Projetos

### [ecommerce-fullstack](https://github.com/NicolasCardoso2/ecommerce-fullstack)

Plataforma de e-commerce completa com catálogo de produtos, carrinho, pedidos, pagamentos e painel administrativo. O back-end roda com Spring Boot 3.5 em Java 25 e o front-end em React com TypeScript. Toda a infraestrutura sobe com um único `docker compose up`.

Tem autenticação JWT com refresh token, controle de acesso por perfil (USER e ADMIN) e rate limiting nos endpoints de login. A observabilidade é feita com Prometheus e Grafana, com dashboards, métricas em tempo real e alertas automáticos.

`Java 25` `Spring Boot 3.5` `React 18` `TypeScript` `PostgreSQL` `Redis` `Docker` `Nginx`

<br>

### [nexloja](https://github.com/NicolasCardoso2/nexloja)

Sistema de gestão de loja desenvolvido **sob encomenda para um cliente real**. Funciona 100% offline, instalado como aplicativo `.exe` no Windows, e cobre caixa, estoque, vendas, clientes e relatórios.

Tem 114 testes unitários com 97% de cobertura nas regras de negócio. A arquitetura segue Clean Architecture com Mappers, Use Cases e Domain Errors bem definidos.

`TypeScript` `React` `Electron` `SQLite` `Zustand` `TanStack Query` `Vitest`

<br>

### [GameDevManager](https://github.com/NicolasCardoso2/GameDevManager)

Ferramenta para game developers gerenciarem projetos, tarefas e check-ins de progresso diários. Funciona como PWA no navegador e como app nativo no desktop via Tauri, com suporte completo a uso offline e sincronização automática quando a conexão volta.

`React 18` `TypeScript` `Firebase` `Firestore` `Tauri` `Zustand` `TanStack Query` `Zod`

<br>

### [task-api-nestjs](https://github.com/NicolasCardoso2/task-api-nestjs)

API REST para gerenciamento de tarefas com autenticação JWT, isolamento por usuário e validação de dados via DTOs. Arquitetura modular com NestJS e banco PostgreSQL, containerizada com Docker Compose.

`NestJS` `TypeScript` `PostgreSQL` `TypeORM` `JWT` `Docker`

<br>

### [design-patterns-java-api](https://github.com/NicolasCardoso2/design-patterns-java-api)

Demonstração prática dos padrões GoF Strategy, Factory e Singleton aplicados em um sistema real de processamento de pagamentos. O código foi pensado para ser extensível: adicionar um novo método de pagamento requer criar apenas uma nova classe, sem alterar as existentes.

`Java 17` `Spring Boot` `Maven`
